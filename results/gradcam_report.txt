1. MODEL USED
   - Model File: models/best_brain_tumor_model.keras
   - Base Architecture: EfficientNetB0 (ImageNet Pretrained)
   - Classification Head: GlobalAveragePooling2D -> Dropout(0.3) -> Dense(4, Softmax)
   - Status: Frozen weights; zero retraining or architectural modification.

2. SELECTED GRAD-CAM LAYER
   - Target Layer Name: top_activation
   - Architectural Location: Final convolutional activation layer of EfficientNetB0 backbone.
   - Layer Details: Activation (SiLU / Swish) following top_conv and top_bn.
   - Spatial Feature Map Dimensions: (1, 7, 7, 1280)
   - Rationale: As the deepest convolutional feature representation before global pooling,
     top_activation contains high-level semantic abstractions with preserved spatial
     geometry, making it the mathematically optimal layer for class activation mapping.

3. INPUT PREPROCESSING
   - Deterministic Pipeline: Exact match with src/predict.py
   - Color Format: Explicit PIL .convert("RGB") ensuring 3-channel input.
   - Resizing: Aspect-ratio preserving LetterboxResize to (224, 224, 3) with black zero-padding.
   - Augmentation: None (strictly deterministic inference).
   - Spatial Alignment: Heatmap (7x7) is upsampled to (224, 224), letterbox padding is
     geometrically uncropped, and the active region is mapped directly back to the
     original image's spatial dimensions (W, H).

6. OUTPUT FILES GENERATED
   For each processed image, 4 distinct visualization artifacts are created in results/gradcam/:
   - original_<stem>.png   : Clean original MRI image.
   - heatmap_<stem>.png    : Isolated colored Grad-CAM activation heatmap.
   - overlay_<stem>.png    : 60/40 alpha-blended overlay onto original MRI.
   - gradcam_<stem>.png    : 3-panel presentation visual with prediction card and notice.

   Total Files Generated in results/gradcam/: 24 image artifacts.

7. PREDICTION CONSISTENCY CHECK
   - Comparison: Verified across test images using src/predict.py and src/explain.py.
   - Result: 100% IDENTICAL. Both pipelines share identical preprocessing and forward pass,
     producing identical predicted classes and class probability vectors to 4 decimal places.

8. IMPLEMENTATION DETAILS & RESOLUTIONS
   - PyTorch Autograd Hook Integration: Leveraged PyTorch forward and backward hooks directly
     on the top_activation module, eliminating symbolic graph disconnection issues in Keras 3.
   - Exact Softmax Calibration: Ensured probabilities in explain.py match predict.py by
     reading the model's output logits/probabilities directly without duplicate softmaxing.
   - Letterbox Inverse Mapping: Implemented geometric un-letterboxing so that zero-padded
     borders do not induce spatial distortion or offset in the final overlay.

9. LIMITATIONS OF GRAD-CAM
   - Feature Coarseness: The spatial resolution of the feature map is 7x7 pixels; upsampling
     to 512x512 produces smooth, broad activation zones rather than pixel-precise boundaries.
   - Non-Diagnostic Nature: Grad-CAM reflects where artificial neural network weights focused
     to maximize a class score, which may correlate with contrast variations, bone margins,
     or tissue textures rather than true histopathological tumor boundaries.
   - Interpretation Constraint: Visual activations must be described strictly as
     "regions contributing to the model's prediction" and NEVER as clinical tumor margins.
