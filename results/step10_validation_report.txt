14. BRAIN MRI INPUT GUARDRAIL
================================================================================
- Implementation: `src/input_guard.py` (BrainMRIInputGuard)
- Architecture: Mandatory gate executed BEFORE preprocessing and BEFORE EfficientNetB0 inference.
- Outcomes Supported:
  1. VALID_MRI -> Inference continues normally.
  2. INVALID_NON_MRI -> STOP. Returns 422/rejected payload. Classifier NEVER executed.
  3. UNCERTAIN -> STOP. Returns 422/rejected payload. Classifier NEVER executed.
- Server-Side Enforcement: Protected in `POST /predict`, `POST /explain`, and `src/predict.py`.
- Critical Safety Intercept Test:
  * Ran 9 controlled test cases in `test_guardrail_pipeline.py`.
  * Monitored model classifier execution via test spy.
  * Result: 0 model executions across all 8 non-MRI / corrupted / uncertain inputs.
  * Output Audit: `results/input_guardrail_test.json` (`invariant_satisfied: true`).
- False Acceptance / Rejection Analysis:
  * Tested skull-edge JPEG compression ringing: Solved by filtering saturation strictly on tissue pixels (V > 0.10).
  * Valid brain MRIs (Glioma, Meningioma, Pituitary, Normal controls) verified with 100% acceptance.
  * Non-MRI images (photos, documents, chest X-rays, abdominal CTs, random noise) rejected 100%.

16. KNOWN LIMITATIONS & RESEARCH CONSTRAINTS
================================================================================
1. Modality Gate, Not Medical Diagnostic:
   The input guardrail validates macroscopic morphological and chromatic image properties.
   It cannot verify scanner calibration, slice sequence protocol (T1, T2, FLAIR, T1ce), or clinical appropriateness.
2. Single-Slice 2D Evaluation:
   The model analyzes 2D axial/coronal slices rather than 3D volumetric MRI sequences.
3. Class Boundary Mimicry:
   As documented in Step 7 error analysis, 56 glioma test scans were misclassified as meningiomas
   due to high visual similarity in peripheral infiltrative boundaries.
