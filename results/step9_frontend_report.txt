3. API ENDPOINTS INTEGRATED (services/api.js)
--------------------------------------------------------------------------------
- Centralized client with AbortController timeout handling (30s max).
- GET /health: Periodic 15s polling to update the navbar connection status pill.
- GET /model-info: Queries model architecture parameters and test accuracy.
- POST /predict: Dispatches multipart/form-data image; receives class prediction and scores.
- POST /explain: Requests Grad-CAM base64 data URIs for overlay, heatmap, and 3-panel figure.
